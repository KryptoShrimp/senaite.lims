Azure AD Configuration Checklist

In Azure Portal (portal.azure.com):

  1. Redirect URIs: Must include:
  2. API Permissions: Should have:
    • Microsoft Graph > User.Read
    • Microsoft Graph > email
    • Microsoft Graph > openid
    • Microsoft Graph > profile
  3. Token Configuration: Optional claims should include:
    • email
    • family_name
    • given_name
    • preferred_username

Supabase Configuration

In Supabase Dashboard:

  1. Authentication > Providers > Azure:
    • Enabled: ✓
    • Client ID: Your Azure App (client) ID
    • Secret: Your Azure client secret value
    • Azure Tenant URL: https://login.microsoftonline.com/YOUR_TENANT_ID

  3. Redirect URLs: Should include your callback URL

Common Issues

Unable to exchange external code

This error typically means:

  • Mismatch between redirect URLs in Azure and Supabase
  • Incorrect client secret in Supabase
  • Azure app registration is missing required permissions
  • Tenant ID mismatch or incorrect format
